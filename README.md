===== МЕНЕДЖЕР ВЫСТАВКИ СОБАК =====
Небольшая консольная программа для проверки навыков работы со списками в C#.
Основной функционал:
  1. Сохранение данных об участниках в список
  2. Добавление и удаление участников
  3. Вывод первых n мест по баллам экстерьера
  4. Поиск собак по породе

В дальнейшем планируются дополнения!
